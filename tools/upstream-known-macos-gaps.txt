# Upstream tests that fail on macOS for platform reasons, not pin reasons.
#
# Each line is a pytest node id. tools/run-upstream-tests.sh reads this file when
# PACT_UPSTREAM_MACOS=1 and deselects these tests, so a local run on macOS can be
# green without pretending the failures do not exist.
#
# Three groups, each an assumption that holds on upstream's Linux CI and not here:
#
# 1. Invalid UTF-8 filenames (Errno 92, "Illegal byte sequence"). APFS refuses to
#    create a path whose bytes are not valid UTF-8; ext4 on Linux accepts them.
#    These tests exist to prove the plugin survives such paths, so they cannot be
#    rewritten to pass here.
# 2. /bin/true. Upstream's home-census tests launch it directly; on macOS the
#    binary is /usr/bin/true.
# 3. CI-only seams: the GITHUB_ACTIONS binding, a hash-pinned pip install line,
#    an unwritable temp directory, and one inode-identity check. These assert on
#    behavior of the CI environment, not of PACT.
#
# Verified: with these deselected the affected files pass on macOS; without the
# pinned dependencies (pytest 9.2.0, pytest-randomly 5.1.0) two further pytest
# internals tests also fail and were fixed by installing the pinned set.
